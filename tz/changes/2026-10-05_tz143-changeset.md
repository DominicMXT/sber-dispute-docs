## 2. Раздел 5.5 — новые строки

| Ситуация | Текст |
|---|---|
| «Пришлось взять» больше отложенного | «Отложено N ₽ — больше взять нельзя.» / «Отложенного пока нет — взять нечего.» |
| Копейки без единицы | «Сумма в рублях, без копеек — например, 5 000.» |
| Номер карты в поле суммы | «Номер карты не нужен — впишите только сумму.» |
| Номер карты в приходе | «Номер карты не нужен — уберите его из фразы.» |
| Темп во фразе | «Если откладывать N ₽ в месяц, к сроку будет M ₽. Нужно ≈ K ₽ в месяц.» или «…к сроку соберётся M ₽ — хватит.» |
| План больше 30 000 ₽ в день | «Это ≈ N ₽ в месяц. Можно сдвинуть срок или цену — «Поправить».» |
| Отмена отметки | «Отмечено сегодня N ₽ · Отменить»; тост «Отметка отменена.» |
| Пустой отзыв Л-10 | «Напишите, что не так — хватит пары слов.» |
| Отзыв отправлен Л-11 | «Читаем каждый отзыв и исправляем.» — без обещания ответить на контакт: поля для контакта нет |
| Приход: обязательные не меньше прихода | кнопка в тексте называется как на экране: «нажмите «Посчитать «Сегодня»» ещё раз» |

## 3. Экраны и вёрстка

- **Э-06.** «Пока сам» → «Пока только я» (нейтрально по роду).
- **Э-01.** Одна строка «Ваши деньги видите только вы» со значком, без второй строки-обрывка.
- **Э-08.** Плёнка — 7 кадров по дням недели вместо 13.
- **Э-08.** Значки видимости показываются, только когда у человека есть общая цель или отправлено приглашение. Пока целей с другими нет, значки ничего не различают. На Э-01 значок остаётся.
- **Л-03.** «Отменить покупку» оформлена как опасное действие.
- **НФТ-ДОС-12 (доп.).**
  - Тост — над нижней зоной, не на заголовке и не на главной кнопке.
  - В альбомной ориентации нижняя зона уходит в поток, если она выше четверти экрана.
  - Панель вкладок не просвечивает.
- **НФТ-ДОС-13 (нов.).** Шрифты не блокируют первую отрисовку: основной (Onest) и рукописный (Caveat) грузятся с `display=swap` без блокировки, остальные — по требованию. В продукте шрифты хостятся у себя, в РФ (вопрос раздела 11, i046).

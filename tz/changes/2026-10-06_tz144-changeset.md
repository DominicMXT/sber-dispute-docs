# Пакет изменений ТЗ 1.4.4 · вход по желанию, считаем всех, все способы входа

06.10.2026 · **применён** — решения владельца после встречи с ментором 06.10.

## Зачем

На встрече ментор сказал три вещи:
- **Кого считают пользователем.** На этапе 1 нужны 50 уникальных пользователей накопительно с выпуска MVP. Анонимные засчитываются, пользователь по cookie — уже пользователь.
- **Регистрация** — шаг воронки в отчёте, а не условие: «пришло 70 → вошли 40 → остались 17».
- **Вход.** Ограничений от программы нет. У других команд — код на почту или Яндекс.

ТЗ 1.4.2–1.4.3 исходило из обратного: DAU только по вошедшим, без входа цель не сохранялась. Обязательный вход терял бы людей, которые и так засчитываются.

## Что меняется

| Пункт | Было | Стало |
|---|---|---|
| ФТ-182 | без входа цель не сохраняется | Л-20 предлагает вход; «Сохранить без входа» сохраняет цель на этом устройстве; повторно в сеансе лист не показывается |
| ФТ-183 | в Р2 — VK ID и Яндекс ID | VK ID, Яндекс ID, Сбер ID — какие подключить первыми, выбирает разработка по скорости, не меньше одного; Сбер ID — после организации |
| ФТ-203 (новое) | — | код на почту: 6 цифр, 10 минут, 5 попыток, адрес — только HMAC, письма — сервис в РФ |
| ФТ-184 | Max — Р4 | без изменений: вход через Max — когда зарегистрирован бот |
| ФТ-187 | DAU только по вошедшим, гости отдельно | пользователи этапа 1 и DAU — все уникальные аккаунты с `app_open`, включая гостей; на панели воронка «пришли → целевой сценарий → вошли → вернулись» |
| 5.5 | — | ошибки почты и кода, тост «Цель сохранена на этом телефоне» |
| НФТ-ПД-20, 25 | — | код на почту среди способов; адрес почты — в согласии как хэш |
| ПК-135, 138, 146 | — | под новые правила |

Google и Telegram для входа по-прежнему не используются: это запрещает 149-ФЗ (ст. 8 ч. 10), за нарушение штрафуют по ст. 13.55 КоАП.

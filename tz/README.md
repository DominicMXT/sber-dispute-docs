# ТЗ для разработки MVP · 25.09.2026

Для разработчика, который собирает продукт с ИИ-агентом. Бизнес-требования (что и зачем) —
`prd/2026-09-25_mvp-prd.html`. Здесь — как проверить, что собрано верно.

## Что внутри

| Файл | Что это |
|---|---|
| `AGENTS.md` | правила для агента: с чего начать, инварианты, что нельзя без человека |
| `openspec/project.md` | назначение, стек, словарь, инварианты, интеграции, открытые вопросы |
| `openspec/changes/mvp-stage1/proposal.md` | зачем, три релиза и порядок среза |

| `openspec/changes/mvp-stage1/specs/*/spec.md` | 9 спецификаций: требования и сценарии приёмки GIVEN/WHEN/THEN |
| `fixtures/` | тестовые векторы: 20 фраз, 7 расчётов, 2 дня, синтетическая выписка с ожидаемым разбором, 4 ссылки |

## Как пользоваться

1. Скопировать `AGENTS.md`, `openspec/` и `fixtures/` в корень репозитория разработки.
2. Попросить агента: «Прочитай AGENTS.md и начни задачу 1.1 из tasks.md».
3. Перед релизом — `openspec validate mvp-stage1 --strict` и все тесты.

Формат выбран, потому что его же выбрал Сбер для разработки по спецификациям (OpenSpec, MIT),
а Claude Code и Cursor читают его без настройки.

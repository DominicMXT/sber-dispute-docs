# Правила для ИИ-агента (Claude Code, Cursor, GigaCode)

Скопируйте этот файл в корень репозитория разработки вместе с папками `openspec/` и `fixtures/`.
Формат — [AGENTS.md](https://agents.md/); спецификации — [OpenSpec](https://github.com/Fission-AI/OpenSpec) (MIT).

## С чего начать

1. Прочитай `openspec/project.md` — назначение, стек, словарь, инварианты.
2. Работай по `openspec/changes/mvp-stage1/tasks.md` сверху вниз. Одна задача — один коммит.
3. Перед кодом задачи прочитай её спецификацию в `openspec/changes/mvp-stage1/specs/<область>/spec.md`. Сценарии GIVEN/WHEN/THEN — это приёмка.
4. Интерфейс сверяй с прототипом `prototype/2026-09-24_mvp-prototype.html` из репозитория документов: любое состояние открывается по `?s=<код>`, коды — в спецификациях.

## Инварианты — нарушать нельзя

- Деньги считает код в `money/`, а не модель. Сначала тест по `fixtures/`, потом функция.
- Числа в тексте GigaChat сверяются с расчётом; не совпало — шаблон.
- Партнёр не получает чужих `share`, `saved`, доходов, трат и выписки — ни в интерфейсе, ни в ответе API.
- Любой текст перед GigaChat проходит общую функцию маскирования.
- Файл выписки не пишется на диск и удаляется в `finally`.
- В журнале `events` нет сумм и текстов.
- Модель — только GigaChat. Другие поставщики не подключать, даже для тестов.
- Лицензии зависимостей — без GPL и AGPL.

## Что делать нельзя без человека

- Коммитить ключи, токены, строки подключения, `.env`. Секреты — только в хранилище облака.
- Коммитить реальные выписки, скриншоты уведомлений, фразы пользователей. Тесты — только на `fixtures/`.
- Менять формулы в `fixtures/*.json` под свой код. Не сходится вектор — останавливайся и спрашивай.
- Добавлять экраны и функции, которых нет в спецификациях.

## Готово — это

- Все сценарии задачи проверены, и есть доказательство: вывод теста, скриншот на 375 px, строка журнала.
- `pytest` и тесты клиента зелёные; прогон 20 фраз GigaChat — отдельной командой перед релизом.
- Задача отмечена `[x]` в `tasks.md` в том же коммите.

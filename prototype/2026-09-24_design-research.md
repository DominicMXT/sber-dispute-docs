## 3. Библиотеки эффектов

По сравнению [PkgPulse, 2026](https://www.pkgpulse.com/guides/react-bits-animated-components-2026) и [DesignRevision](https://designrevision.com/alternatives/magic-ui) [мнение]:

| Библиотека | Для чего | Лицензия | Нам |
|---|---|---|---|
| [Motion](https://motion.dev/) (бывш. Framer Motion) | Движение в приложении: жесты, пружины, переходы между экранами | MIT | **Да** — основа движения. Пружины Material 3 Expressive переносятся в его параметры |
| Animate UI | Микровзаимодействия приложения: нажатия, загрузка, переходы | MIT | Да, выборочно |
| Magic UI | Эффекты для лендингов: бегущие строки, лучи, сетки | MIT | Только для лендинга листа ожидания, не в продукт |
| React Bits | Эффекты текста (появление цифр, размытие) | MIT + Commons Clause (нельзя перепродавать саму библиотеку, приложения делать можно) | Возможно — анимация главного числа. Проверить условие Commons Clause |
| Aceternity UI | Эффектные блоки для маркетинга | MIT | Нет — «вау» против доверия |

Ни в одном сравнении нет слов о `prefers-reduced-motion` — это наша обязанность, не библиотек.

## 4. heroes.camp — что берём

Снято с сайта 24.09 [факт]: заголовок первого экрана — антиква Source Serif 4, текст — Fira Sans; чернила тёмно-синие, акцент фиолетовый, второй акцент коралловый, подложки светло-лавандовые, первый экран на кремовом фоне; кнопки 10 px скругления, 15 px, 500; анимации: пульс точки «идёт набор», покачивание иллюстраций, всплытие листов, рост полосок.

Берём приёмы [моё]:
1. ~~Крупная антиква для главной фразы~~ — не взято: спорит с Plasma; главная фраза — SB Sans Display.
2. Подписи-метки над значениями (КОМУ · ФОРМАТ · КОГДА) — у нас «Ваша часть», «Отложено».
3. Одна насыщенная кнопка на экран, вторая — контуром.
4. Живая точка у статуса («идёт набор») — у нас у «партнёр ещё не открыл» и «по плану».
5. Рост полоски прогресса при появлении.

Не берём: палитру и шрифты целиком — это бренд школы, а не наш.

## 5. Решение (владелец: «нужно лучшее решение», 24.09)

- **Основа — Plasma Giga**: язык экосистемы организатора, готовые React-компоненты, версии для Android, шрифты с CDN в России, MIT.
- **Продуктовый слой** — метка видимости и тёмные оттенки статусов: зелёный и оранжевый Plasma не проходят AA для мелкого текста (3,51 и 3,13; посчитано скриптом).
- **Движение** — пружины Material 3 из исходников androidx: standard для переходов, expressive только для «сходится / отложил»; деньги — без перелёта.
- **Носитель правил** — `prototype/DESIGN.md` по формату Google Labs.
- **Эффекты в продукте** — Motion и Animate UI; Magic UI — только для лендинга листа ожидания.
- **Из heroes.camp** взяты подписи над значениями, одна главная кнопка на экран, живая точка у ожидания, рост полоски прогресса.

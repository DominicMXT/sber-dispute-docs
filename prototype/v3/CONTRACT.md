# Контракт волны 3: прототип «Туман» v3

Прототип v3 = `2026-10-04_fog-prototype-v2.html` + модули из этой папки. Сборка — `python ../build_v3.py`.
Решения владельца 04.10: пивот на помощника для одного с подключением людей; ядро — цели к дате и «сегодня на себя»;
видимость в общей цели — своя часть и огрублённый прогресс; тёмная тема с переключателем; анимации на действия;
механики мотивации; вход: Э-01 → пример Э-08 → «Создать свою цель» → Э-02…Э-06. Релиз нового — Р2.

## Кто что правит

| Модуль | Владелец | Волна | Что делает |

**Правишь только свой модуль.** `v2.html`, `build_v3.py`, чужие модули и этот файл не трогаешь. Нужна точка в чужом
коде — напиши об этом в отчёте, интегратор добавит.

## Как устроен модуль

```python
R = [("точная строка из v2", "замена"), ...]   # каждая строка встречается в v2 ровно 1 раз — иначе сборка падает
CSS = """..."""                                 # в конец <style>
JS = """..."""                                  # перед «/* ── запуск ── */»: все функции v2 уже объявлены
```

**Порядок наложения:** `flow_group` → `motivation` → `theme` → `anim`.
- Если тебе нужно изменить место, которое правит модуль раньше тебя, лучше обойтись JS-обёрткой.
- Функции v2 объявлены через `function`, их можно переопределить: `const _x = scrPurchase; scrPurchase = function(){...}`.
- Объекты `SCR`, `SH`, `V3_SCEN` можно дописывать.

**Проверка у себя:** `python ../build_v3.py --only <модуль>` → `_test_<модуль>.html` и `node --check`. Затем полная сборка `python ../build_v3.py`.
Открыть в браузере — `http://localhost:8767/prototype/v3/_test_<модуль>.html#<код>`; сервер `sber500-docs` запускает интегратор.

## Решения владельца после ревью (05.10, волна 5)

- **Статус участника на 3–6 — только «по плану».** У остальных плашки нет; «отстаёт», «только начали» не показываются никому, кроме самого человека. Подотчётность — агрегатом в итогах недели («по плану 3 из 4»).
- **Статус считается из того же суточного снимка, что и общий %,** а порог плана — от даты входа участника, не от создания цели (QA №1, №7): иначе по моменту смены статуса вычисляется чужая сумма.
- **Значки видимости остаются нейтральными (серыми)** — акцент только у нажимаемого. Значки расшифровываются словами один раз: на экране согласия Э-01 и в листе «Как это работает?»; сам значок чуть крупнее.
- **Сдвиг срока в общей цели — предложением.** «Сдвинуть срок» отправляет предложение без причин и сумм; срок меняется, когда согласны все участники. До согласия человеку предлагается догнать свою часть. В своей цели — как сейчас, сразу.

**Ещё 05.10 (после ревью волны 5):**
- **Сторис остаются:** Э-01 знакомство (до 5 карточек) → согласие → пример → своя цель. Тексты карточек — под пивот, без «пары».
- **Статус «по плану» других — пересчёт раз в сутки** (подтверждено).
- **Сдвиг срока не предлагается, если доплата < 150 ₽ в день:** одна кнопка «Догнать», сдвиг — вторичной ссылкой.
- **Тексты длиннее бюджета** («Мои данные», листы о данных и напоминаниях) сокращаются; полный юртекст — по «Подробнее», на визу юриста.

## Правила для всех

- **Тексты по бюджету ТЗ 5.1:**
  - первый экран — не больше 45 слов;
  - предложение — не больше 15 слов;
  - лист — не больше 30 слов;
  - кнопка называет действие.
- **Значки видимости** на блоках с деньгами: замок — «видно только вам», два человека — «видит партнёр»; в группе — «видят участники».
  У значка `aria-label`.
- **Без красного и упрёков.** Отставание пишется нейтрально.
- **Чужих сумм нет нигде:** ни в тексте, ни в ответе GigaChat, ни в уведомлении.
  - В общей цели двоих — только «сходится / нет».
  - При трёх и больше — прогресс с шагом 10 %.
  - Обещанная часть («беру 15 000 ₽») видна всем как договорённость.
- **Движение:**
  - кривые `--ease-out`, `--ease-in-out`, `--ease-drawer`;
  - анимируются только `transform`, `opacity`, `clip-path`;
  - исключение — смена темы: `background-color`, `color`, `border-color` 250 мс, только пока на `<html>` висит `.theme-anim` (DESIGN.md, таблица движения);
  - при `prefers-reduced-motion` — мягче или без движения.
- **Без новых внешних ресурсов.** Шрифты уже подключены — Onest и Caveat.
- **Демо-имена** вымышленные: Олег, Аня; в группе ещё Тимур и Света.
- **Отчёт агента:** что сделано, коды состояний, вывод сборки `--only` и полной сборки, чего не сделал и почему.
